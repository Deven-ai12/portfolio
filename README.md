## `03` — Featured Projects

### ⚡ TradeFlow

**Real-time trading-style full-stack web application**

TradeFlow is a full-stack trading platform designed to simulate core trading workflows while demonstrating authentication, portfolio management, wallet operations, watchlists, and market-data integration.

**Architecture**

```text
React
  ↓
REST API
  ↓
Spring Boot
  ↓
Spring Security + JWT
  ↓
JPA / Hibernate
  ↓
MySQL
  ↓
Finnhub Market Data
```

**Built with**

`Java` `Spring Boot` `Spring Security` `JWT` `React` `MySQL` `JPA` `Hibernate` `Finnhub`

**Key features**

* 🔐 JWT authentication & authorization
* ✉️ Email verification
* 💰 Wallet management
* 📈 Buy / Sell trading operations
* 📊 Portfolio tracking
* ⭐ Watchlist
* 🌐 Market data integration
* 🗄️ MySQL database
* 🔒 Spring Security
* 🚀 RESTful backend architecture

**Repository**

[→ View TradeFlow Backend](https://github.com/Deven-ai12/tradeflow-backend)

## `06` — Run Locally

### Clone

```bash
git clone https://github.com/Deven-ai12/portfolio.git
```

### Enter project

```bash
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

### Production build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
